# Misfit Mountain Bingo — Project Notes

## Project
Misfit Mountain Bingo — a cozy mobile bingo game set in the Misfit Mountain universe.

## Direction (locked)
- **Lane:** social-casino bingo (free-to-play, virtual currency, IAP-only). Not skill-cash, not sweepstakes.
- **Audience:** the existing mobile-bingo audience — skews older and female, plays bingo because it is *relaxing*. Honor that.
- **Tone:** cozy, warm, low-stakes feel. Not edgy, not RPG-energetic, not slot-machine tense.
- **Host:** Wisper is the on-screen caller and guide character. Voice-acted, with personality.
- **Setting:** themed rooms are Misfit Mountain regions (replacing the genre-standard "world tour" geography).
- **Meta:** collection album of cozy Misfit Mountain artifacts (charms, keepsakes, postcards, recipes — *not* creatures to capture). Think "Wisper's Scrapbook," not "Pokédex."

## Out of scope (do not propose without checking with Ed)
- Creature combat / type matchups / RPG mechanics
- PvP creature battles, raid bosses
- Skill-based real-money play (Skillz / Big Run model)
- Sweepstakes / dual-currency cash redemption
- Anything that pushes the tone toward "young/RPG energetic" or "slot-machine tense"

## Status
Scaffold + genre research only. Detailed game design, mechanics, and tech stack are still TBD. Don't invent specifics without checking with Ed.
